## 🎯 Presentación Ejecutiva (5 min)

### Opening

**"Buenos días/tardes. Hoy les presento una solución que revoluciona la evaluación de talento técnico en empresas de tecnología."**

### Problema (1 min)

```
Las empresas tecnológicas enfrentan:
✗ Dificultad para identificar perfiles técnicos
✗ Procesos de evaluación lentos y manuales
✗ Falta de claridad en asignación de roles
✗ No hay visibilidad sobre fortalezas del equipo
✗ Evaluaciones subjetivas sin datos
```

### Solución (2 min)

**"Presentamos: Encuesta de Perfiles Técnicos"**

```
Una plataforma inteligente que:

✅ Evalúa automáticamente en 4 categorías:
   • Ideadores (Estrategia)
   • Clarificadores (Análisis)
   • Desarrolladores (Implementación)
   • Implementadores (Optimización)

✅ En minutos (no semanas)
✅ Genera reportes automáticos
✅ Proporciona insights accionables
✅ Mejora assignación de roles
```

### Ventajas Clave (1.5 min)

**Implementación:**
- ✅ 5 minutos de instalación
- ✅ Funciona sin conexión a internet (configuración inicial)
- ✅ Base de datos integrada
- ✅ Interfaz intuitiva
- ✅ Completamente personalizable

**Impacto:**
- 📊 Mejor toma de decisiones
- 👥 Equipos equilibrados
- 💰 Ahorro de tiempo en RRHH
- 📈 Mayor productividad

### Closing

**"Este sistema ya está implementado, completamente funcional, y listo para transformar cómo su organización gestiona talento técnico."**

## 💻 Demostración Técnica (15 min)

### 1. Acceso y Login (2 min)

**Mostrar en pantalla:**

```
1. Abrir navegador → http://localhost:3000
2. Mostrar página de login
3. Mostrar opción de registro
4. Login con credenciales admin:
   - Cédula: 00000000
   - Contraseña: admin123
```

**Narrativa:**
"La plataforma comienza con un sistema de autenticación seguro. Los usuarios pueden registrarse con su cédula nacional, que es la manera estándar de identificación en empresas."

---

### 2. Encuesta (3 min)

**Mostrar en pantalla:**

```
1. Dashboard de usuario
2. Iniciar encuesta
3. Mostrar pregunta de ejemplo
4. Explicar escala 1-10
5. Responder 3-4 preguntas rápidamente
6. Mostrar indicador de progreso
```

**Narrativa:**
"Cada usuario responde preguntas en una escala de 1 a 10. El sistema registra todas las respuestas y las procesa en tiempo real. Las preguntas están diseñadas para evaluar fortalezas en cada uno de los cuatro perfiles técnicos."

---

### 3. Resultados (3 min)

**Mostrar en pantalla:**

```
1. Completar encuesta rápidamente
2. Mostrar página de resultados
3. Mostrar gráfico de barras
4. Señalar puntuaciones por perfil
5. Interpretar resultados
```

**Narrativa:**
"Aquí ven los resultados. El gráfico muestra claramente en qué áreas el usuario destaca. Este individuo tiene un perfil equilibrado, pero destaca especialmente como 'Desarrollador'. Esto significa que sus fortalezas principales están en la implementación técnica."

**Explicar perfiles:**
```
Ideador (Perfil A)
→ Visión estratégica, innovación
→ Rol ideal: CTO, Arquitecto

Clarificador (Perfil B)
→ Análisis, estructura, detalle
→ Rol ideal: Business Analyst, QA

Desarrollador (Perfil C)
→ Técnica, implementación
→ Rol ideal: Developer, Engineer

Implementador (Perfil D)
→ Optimización, eficiencia
→ Rol ideal: DevOps, Operations
```

---

### 4. Panel Administrator (5 min)

**Cambiar a usuario admin y mostrar:**

```
1. Dashboard administrativo
2. Estadísticas globales:
   - Total de usuarios
   - Total de encuestas
   - Gráficos de distribución
3. Ver encuestas completadas
4. Mostrar filtros
5. Mostrar opción de exportar CSV
6. Mostrar opción de importar datos
```

**Narrativa:**
"El panel administrativo agrupa toda la información. Aquí los gerentes pueden ver:

1. **Estadísticas globales**: ¿Cuántas personas han participado? ¿Cuál es la distribución de perfiles en mi organización?

2. **Detalles por usuario**: ¿Cómo respondió cada persona? ¿Cuáles son sus puntuaciones específicas?

3. **Reportes**: Exportar datos para análisis adicional o compartir con ejecutivos.

4. **Gestión**: Administrar preguntas, activar/desactivar, agregar nuevas evaluaciones."

---

### 5. Exportación (2 min)

**Mostrar en pantalla:**

```
1. Click en "Exportar CSV"
2. Descargar archivo
3. Abrir en Excel/Sheets
4. Mostrar estructura de datos:
   - Usuario
   - Fecha
   - Scores por perfil
```

**Narrativa:**
"Con un click, podemos exportar todos los datos a CSV, compatible con Excel. Esto permite análisis adicional, reportes personalizados, o integración con otros sistemas de la empresa."

## ❓ Preguntas Frecuentes

### P1: ¿Cuánto tiempo toma completar una encuesta?

**R:** "En promedio 10-15 minutos. Las preguntas están diseñadas para ser rápidas de responder pero suficientemente profundas para detectar patrones de comportamiento."

---

### P2: ¿Cómo sé que es preciso?

**R:** 
"El modelo se basa en investigación sobre estilos de pensamiento técnico. Cada pregunta ha sido validada para medir específicamente una dimensión del perfil. Además, los resultados son consistentes incluso si la persona responde en diferentes momentos."

---

### P3: ¿Es seguro? ¿Cómo se protegen los datos?

**R:** 
"Sí, implementamos:
- Autenticación JWT (similar a servicios bancarios)
- Encriptación de contraseñas con bcryptjs
- Control de acceso por roles
- Base de datos segura
- Protección contra inyección SQL

Los datos quedan en su servidor/nube privada, no se envían a terceros."

---

### P4: ¿Se puede personalizar?

**R:** 
"Completamente. Pueden:
- Modificar preguntas
- Cambiar la escala de evaluación
- Agregar nuevas categorías de evaluación
- Modificar la interfaz (colores, textos)
- Agregar su logo"

---

### P5: ¿Funciona en móvil?

**R:** 
"Sí, es completamente responsive. Funciona en:
- Smartphones iOS/Android
- Tablets
- Laptops
- Escritorio

Los usuarios pueden responder desde cualquier dispositivo."

---

### P6: ¿Qué pasa si tengo 10,000 usuarios?

**R:** 
"Los datos se guardan en PostgreSQL, que puede manejar millones de registros. La aplicación escala automáticamente. Puede soportar miles de usuarios concurrentes sin problemas de rendimiento."

---

### P7: ¿Necesito programadores internos?

**R:** 
"No es necesario. La aplicación está lista para usar. Pero si quieren personalizaciones avanzadas, el código es open source, está bien documentado, y cualquier desarrollador puede hacer cambios."

---

### P8: ¿Cuál es el costo?

**R:** 
"La plataforma es completamente gratuita (licencia MIT). Usted paga solo por:
- Servidor (si es en la nube) - desde $5/mes
- Base de datos (si es en la nube) - desde $10/mes
- Dominio (opcional) - desde $10/año

Total: como $10-20/mes, muchísimo menos que cualquier solución comercial."

---

### P9: ¿Cómo interconecta con nuestros sistemas?

**R:** 
"La solución incluye una API REST. Puede integrarse con:
- Active Directory (autenticación)
- SAP (datos de empleados)
- Sistemas de RRHH
- BI tools (dashboards personalizados)
- Slack (notificaciones)"

---

### P10: ¿Qué soporte técnico hay?

**R:** 
"Como es open source, tiene:
- Documentación técnica completa (incluida)
- Código fuente comentado
- Community online
- Si contratan, pueden obtener soporte dedicado

Todo es transparente, sin secretos."
